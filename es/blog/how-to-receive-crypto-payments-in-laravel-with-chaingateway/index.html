Recibir pagos cripto en Laravel: guía práctica

Tutorial paso a paso: cómo construir una pasarela de pago en Laravel que recibe TRX y USDT (TRC20) a través de la API de Chaingateway.

Capítulos
C
Chaingateway Team
Expertos en blockchain

Este tutorial le guiará en la construcción de una pasarela de pago en Laravel compatible con pagos en Tron (TRC) y JST (TRC20). Incluye funciones como generar wallets para sesiones de pago, gestionar webhooks para notificaciones de transacciones y verificar el estado de la transacción antes de procesarla.

Al final de este tutorial, tendrá una pasarela de pago funcional que usa la API de Chaingateway para las interacciones con la blockchain.

Este tutorial solo pretende describir el proceso básico de cómo funciona la implementación. También funcionará para Bitcoin, Ethereum, Binance Smart Chain y Polygon con algunas pequeñas adaptaciones.

💡

No use esto en producción. El programa almacena las claves privadas en texto plano, algo que nunca debería hacerse en un entorno de producción.

💻

El código está disponible en https://github.com/chaingateway/chaingateway-crypto-payment-demo-laravel.git

Introducción

Antes de entrar en la implementación, entendamos las herramientas que vamos a usar:

¿Qué es Chaingateway?

Chaingateway es un servicio de API de blockchain que simplifica la interacción con redes blockchain como Tron. Le permite:

  • Generar direcciones de wallet.
  • Monitorizar transacciones.
  • Ejecutar transacciones de forma programática.

Visite la documentación oficial para más detalles:

  1. Developer Portal: aprenda a usar las funciones de Chaingateway.
  2. Documentación de la API: explore los endpoints de la API en detalle.
  3. Creación de clave API: genere las claves API necesarias para la autenticación.

Pasos para crear una clave API

Para interactuar con la API de Chaingateway, necesitará una clave API. Siga estos pasos:

  1. Inicie sesión en Chaingateway.
  2. Vaya a User Settings > API Tokens.
  3. Haga clic en Create Token, dele un nombre a su token (por ejemplo, “Payment Gateway”) y cópielo. Usará esta clave en su aplicación Laravel.

Requisitos previos

Antes de continuar, asegúrese de tener:

  1. Una instalación de Laravel: un proyecto Laravel recién configurado. Siga la guía de instalación de Laravel si es necesario.
  2. Configuración de la base de datos: actualice su archivo .env con sus credenciales de base de datos.
  3. Conocimientos básicos de Laravel: es útil estar familiarizado con models, migrations, controladores y rutas.

Funciones del tutorial

Este tutorial construye una pasarela de pago con las siguientes funciones:

  1. Un formulario dinámico para iniciar sesiones de pago:
    • Los usuarios pueden introducir el importe del pago.
    • Los usuarios pueden seleccionar la divisa (TRX o USDT).
  2. Se asocia una dirección de wallet generada a cada sesión.
  3. Una página de sesión que muestra:
    • La dirección del wallet.
    • El estado de la sesión.
    • El importe a enviar, el importe recibido y la divisa.
  4. Un webhook que se encarga de:
    • Verificar las transacciones entrantes.
    • Actualizar el estado de la sesión.
    • Reenviar los fondos a un cold wallet tras un pago exitoso (opcional).

  3. Ver una sesión de pago.
  4. Gestionar webhooks.

Explicación
