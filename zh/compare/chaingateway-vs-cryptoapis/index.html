选择 Crypto APIs 还是 Chaingateway？

如果……，选择 Crypto APIs
  • 你需要比 Chaingateway 的七条链更多的网络 — Crypto APIs 列出 35+ 个。
  • 你想在同一个 API 密钥下做地址和交易的 AML 筛查。
  • 你想要更长的试用期：14 天、10 万积分、含主网，无需付款方式。
  • 你愿意基于 xPub 准备交易并在自己的服务器上签名，并希望用 pay-as-you-go 积分包应对高峰。
如果……，选择 Chaingateway
  • 你想要以交易、钱包、Webhook 和请求数计的固定月度限额，而不是积分余额。
  • 你想用加密货币支付订阅费。
  • 你希望由 API 代为签名：受密码保护的钱包让你无需自己处理原始私钥即可发送。
  • 你想无需信用卡、无需 KYC 试用 7 天，且每个套餐使用同一套 API。

常见问题：Chaingateway 与 Crypto APIs

Crypto APIs 的订阅以积分计量：Starter 为 49 美元/月，含 3000 万积分（Scale 299 美元，Pro 799 美元），按年付费可降低月费，积分用尽时由预付积分包补充。Chaingateway 出售四档固定月费套餐（49 欧元起），限额按交易、钱包、Webhook 和请求数固定。单位不同，请用你预期的业务量分别核算。

Crypto APIs：每个产品一次 14 天试用，含 10 万积分，含主网和测试网，无需付款方式。Chaingateway 在每个套餐上提供 7 天，开始测试无需信用卡、无需 KYC。

Crypto APIs 列出 35+ 个网络。Chaingateway 支持七条：Bitcoin、Ethereum、TRON、Solana、BNB Smart Chain、Polygon 和 Arbitrum，每个套餐使用同一套 API。

两者都称自己是非托管。在 Crypto APIs，你从 xPub 派生地址并在自己的服务器上签名交易。在 Chaingateway，你可以使用受密码保护的钱包（密钥加密存储，密码从不存储），或使用未加密保护的地址，此时 API 会把私钥返回给你。
