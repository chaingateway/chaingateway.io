Chaingateway Webhooks 是一项服务，每当发生相关事件（例如转入或转出交易）时，会向你指定的 Endpoint 发送 POST 请求，让你实时接收区块链事件通知。

即时支付通知（IPN）是 Chaingateway 在每次发生相关区块链事件（例如转入或转出交易）时，发送到你指定 Endpoint 的一条消息。它让你能够实时获取更新，并根据事件数据立即采取行动。

要设置 Webhook，你需要在服务器上创建一个能够接收 POST 请求的安全 Endpoint。然后可以使用 Chaingateway 控制台或 API 创建 Webhook，并指定 Endpoint 的 URL，以及你想接收通知的事件所需的筛选条件。

你必须提供 url（公开 Endpoint），并至少提供 from 或 to 中的一个。其他可选的筛选参数包括 contractaddress、token_id 和 type（Ethereum 为 ETH/ERC20/ERC721，其他链类似）。

每个 POST 请求都包含 id、webhook_id、from、to、blocknumber、datetime、tokenid、type、contractaddress、txid、amount 以及其他记录字段，让你能够核对支付信息。

每次推送都会附带 X-Signature 签名（基于 txid + 你的密钥，使用 HMAC SHA-256 计算并以 Base64 编码）。失败的调用会在 72 小时内持续重试，并出现在推送日志中，方便你重放或收到提醒；测试事件可帮助你在开发阶段验证处理逻辑。

使用 Chaingateway 控制台向你的 Endpoint 发送测试事件，在正式上线前验证你的处理逻辑能否正确处理 Payload。

使用 X-Signature 请求头验证传入请求确实来自 Chaingateway。该签名使用你的密钥通过 HMAC SHA-256 生成，确保你的 Endpoint 只处理经过授权的事件。
