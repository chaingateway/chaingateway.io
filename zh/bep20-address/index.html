BEP20 地址是 42 位、以 0x 开头的十六进制字符串，用于在 BNB Smart Chain 上持有 BNB 和 BEP-20 代币——与以太坊使用的地址格式相同，因为 BSC 的执行层与 EVM 兼容。如果你正在对接 BSC 存款或提现，地址是每个流程的起点：为每位客户生成一个，监控它，确认到账后入账。本页介绍地址格式，以及如何通过 API 而非钱包界面获取地址；关于校验和以及 BEP-2 与 BEP-20 区别的更深入技术说明，请参阅博客上的 BEP20 地址指南。

什么是 BEP20 地址？

BEP20 地址是一个 20 字节的值，写作 40 位十六进制字符并带 0x 前缀——例如 0x8894E0a0c962CB723c1976a4421c95949bE2D4E。它的生成方式与以太坊地址相同：由密钥对的公钥通过 Keccak-256 哈希得出。正是这种共享的生成方式，使得持有以太坊地址的钱包能在 BSC 上显示完全相同的字符串——地址格式本身不区分链，区分链的是你广播交易时所面向的网络。

BSC BEP20 与 BEP-2：并非同一标准

BEP20 是 BNB Smart Chain 的代币标准，功能上接近以太坊的 ERC-20，并使用相同的地址格式。BEP-2 是另一个更早的标准，运行在 BNB Beacon Chain（原 Binance Chain）上，拥有自己的地址格式，以 bnb1 而非 0x 开头。「BSC BEP20」和「BEP-2」地址不可互换，将 BEP-2 资产发送到 BEP20 格式的地址（或反过来）会失败，在部分交易所则需要额外的跨链转换步骤。如果你是通过「bep20 bsc」搜索到这里的，关键区别就在这里：你所在的链是对的。

BEP20 钱包地址在实践中是什么？

从功能上说，BEP20 钱包地址是你在 BSC 上的账户标识：接收传入 BNB 或 BEP-20 代币（例如 USDT、USDC 或某个项目自己的代币）的目标地址，以及发出转账的来源地址。同一个 binance smart chain 钱包地址格式可以同时持有原生 BNB 和每一种 BEP-20 代币——每个账户对应一个地址，而不是每种资产一个地址，某个代币在该地址下的余额由该代币自己的智能合约追踪，而不是由地址本身记录。

通过 REST 创建并监控 BEP20 地址

无需在钱包应用中生成地址再复制到后端，BSC API 可直接创建和导入地址，存款到账时由 Webhook 通知你。

接口作用
POST /api/v2/bsc/addresses生成新的 BEP20 地址
POST /api/v2/bsc/addresses/import导入已有私钥，让 API 能够代表该地址签名
POST /api/v2/bsc/webhooks为该地址注册 Webhook，存款到账时触发 HMAC 签名回调
GET /api/v2/bsc/webhooks/notifications获取历史存款通知列表，用于对账

监控一个地址的存款情况无需导入私钥——只有从该地址发送资金才需要。这一点对 BEP20 代币很重要：你的存款收集地址可以始终保持只读监控，只有负责付款的热钱包才需要导入私钥。
