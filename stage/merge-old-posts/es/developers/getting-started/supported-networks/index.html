Redes blockchain y testnets compatibles

Chaingateway admite siete blockchains: Ethereum, TRON, BNB Smart Chain, Bitcoin, Polygon, Arbitrum y Solana. Cada una tiene mainnet y testnet. Usted elige la red en cada solicitud con la cabecera X-Network, que toma el valor mainnet o testnet, y el segmento de la ruta selecciona la blockchain, por ejemplo /api/v2/tron/....

¿Cómo cambio entre mainnet y testnet?

Sección titulada «¿Cómo cambio entre mainnet y testnet?»

Añada la cabecera X-Network: testnet para ejecutar una solicitud en la red de pruebas. Elimine la cabecera, o envíe mainnet, para usar la red principal. El archivo OpenAPI define la cabecera como opcional con el valor por defecto mainnet, así que una solicitud sin ella se ejecuta en la red principal. La llamada siguiente lee el último bloque de Ethereum Sepolia.

Las listas de notificaciones de webhook se limitan a una blockchain y una red, así que envíe el mismo valor de X-Network al leerlas que al crear el webhook. Use un solo token de API para ambas redes y fije la cabecera en la configuración del cliente, de modo que un entorno de pruebas no llegue a mainnet por error.

Las familias de endpoints se parecen, pero cada blockchain tiene su propio modelo de transacciones, así que algunos parámetros cambian. La tabla resume lo que define el archivo OpenAPI para cada una.

Solana no tiene endpoints de webhook. Para detectar un ingreso en Solana, consulte el saldo a intervalos o liste las transacciones. En las cadenas EVM y en Tron puede crear en su lugar un webhook.

¿Cómo compruebo que una red está accesible?

Sección titulada «¿Cómo compruebo que una red está accesible?»

Llame a GET /api/v2/{chain}/blocks/number para la blockchain y la red que quiera probar. El endpoint existe en las siete blockchains y devuelve el número del último bloque. Una respuesta con ok: true indica que su token, la ruta y la cabecera X-Network son correctos. Una respuesta 401 con Unauthenticated. apunta al token, y un 404 apunta a una ruta equivocada. Ejecute la llamada una vez para mainnet y otra con X-Network: testnet después de cambiar la configuración.

¿Dónde consigo monedas de testnet y exploradores?

Sección titulada «¿Dónde consigo monedas de testnet y exploradores?»

Las monedas de testnet vienen de faucets que mantienen las comunidades de cada blockchain, no Chaingateway. La documentación para desarrolladores de cada blockchain lista los faucets, exploradores y parámetros de red actuales. Consulte esas páginas antes de probar, porque las testnets se reinician o se sustituyen de vez en cuando.

  • Ethereum: resumen de redes con testnets y faucets.
  • TRON: documentación de redes para mainnet y la testnet Nile.
  • BNB Smart Chain: documentación para desarrolladores y la lista de endpoints JSON-RPC.
  • Polygon: referencia de endpoints RPC para Amoy.
  • Arbitrum: información de las cadenas para Arbitrum One y Arbitrum Sepolia.
  • Bitcoin: guía de pruebas para testnet y regtest.
  • Solana: documentación de clústeres para devnet.
