FAQ de la API blockchain para desarrolladores

Estas preguntas frecuentes responden a lo que más preguntan los desarrolladores sobre la API de Chaingateway: autenticación, redes, pruebas, errores y soporte. Chaingateway es una API REST con la que una aplicación crea wallets, envía transacciones, lee datos de la blockchain y recibe webhooks. Cada respuesta enlaza a la página con los detalles.

¿Cómo empiezo y me autentico?

Sección titulada «¿Cómo empiezo y me autentico?»

Registre una cuenta, cree una clave de API en el panel y envíela como token Bearer. La prueba gratuita de 7 días no requiere tarjeta. El inicio rápido explica la primera solicitud.

¿Qué es Chaingateway.io? Chaingateway.io es una plataforma que ofrece soluciones de API blockchain y permite a los desarrolladores integrar funcionalidades blockchain en sus aplicaciones. Una sola interfaz REST cubre wallets, transacciones, saldos, bloques y webhooks en varias redes blockchain.

¿Cómo empiezo con Chaingateway.io? Para empezar, regístrese en Chaingateway.io. Una vez registrado, puede crear una clave de API en el panel, en la sección de tokens de API. La necesita para autenticar sus solicitudes a la API. La documentación ofrece guías y ejemplos para ayudarle a integrar la API en su aplicación.

¿Cómo autentico mis solicitudes a la API? Las solicitudes a la API de Chaingateway.io deben autenticarse con una clave de API. Cree la clave en el panel tras iniciar sesión. Envíela como token Bearer en las cabeceras de sus solicitudes HTTP:

Una solicitud sin un token válido devuelve HTTP 401 con el cuerpo {"message":"Unauthenticated."}. No ponga la clave en código del lado del cliente ni en un repositorio.

¿Existen límites de uso para las API? Sí, hay límites de uso según su plan de suscripción. Los planes de niveles superiores ofrecen cuotas de uso más altas. Encontrará información detallada sobre los límites y los precios en nuestra página de precios. Por ejemplo, crear más direcciones de las que permite su plan devuelve el estado 422 con el mensaje Your address limit exceeded. Please upgrade your plan.

¿Qué redes y endpoints hay disponibles?

Sección titulada «¿Qué redes y endpoints hay disponibles?»

La API admite siete blockchains, cada una con mainnet y testnet, y ofrece en ellas gestión de wallets, gestión de transacciones, webhooks y consulta de datos. Redes compatibles lista las redes y los valores de la cabecera X-Network.

¿Qué redes blockchain son compatibles? Chaingateway.io es compatible con las siguientes redes blockchain:

  • Ethereum (mainnet y Sepolia)
  • Binance Smart Chain (mainnet y testnet)
  • Bitcoin (mainnet y testnet3)
  • Polygon (mainnet y Amoy)
  • Tron (mainnet y Nile)
  • Arbitrum (mainnet y Arbitrum Sepolia)
  • Solana (mainnet y devnet)

Para más información sobre cómo acceder a las distintas redes, visite Redes compatibles.

¿Qué tipo de API ofrece Chaingateway.io? La API cubre estas áreas:

  • Gestión de wallets: crear y gestionar wallets.
  • Gestión de transacciones: enviar monedas nativas y tokens, y leer transacciones.
  • Instant Payment Notification: recibir notificaciones webhook sobre eventos de la blockchain.
  • Recuperación de datos: obtener datos de la blockchain, como saldos, bloques y precios de mercado.

El archivo OpenAPI lista más de 200 operaciones. La referencia de la API documenta cada una.

¿Puedo probar las API en un entorno sandbox? Sí, cada blockchain compatible tiene una testnet. Añada la cabecera X-Network: testnet a una solicitud para ejecutarla en la red de pruebas. Sin la cabecera, o con X-Network: mainnet, la solicitud se ejecuta en la red principal. Así puede probar su integración sin mover fondos reales.

Consulte Redes compatibles para saber cómo acceder a las distintas redes.

¿Cómo gestiono los errores y los fallos de webhooks?

Sección titulada «¿Cómo gestiono los errores y los fallos de webhooks?»

Compruebe el campo ok de cada respuesta y registre message y errors cuando sea false. Las entregas de webhook que fallan no se reintentan automáticamente. Usted las lista y las vuelve a enviar.

¿Cómo gestiono los errores de la API? Si una solicitud a la API falla, la respuesta incluye un estado y un mensaje que indican el problema. El archivo OpenAPI documenta estos códigos de estado:

  • 400: Bad Request. Ejemplo: no se pudo leer el contrato TRC20.
  • 401: Unauthorized. La clave de API no es válida o falta, o la contraseña del wallet es incorrecta.
  • 404: Not Found. Ejemplo: un id de webhook que no existe.
  • 422: Unprocessable Entity. La solicitud estaba bien formada, pero falló la validación o la blockchain rechazó la transacción, por ejemplo por fondos insuficientes.

¿Cómo recibo avisos de los pagos entrantes? Cree un webhook con POST /api/v2/{chain}/webhooks. Chaingateway envía entonces una solicitud HTTP POST a su URL por cada transacción que coincide. Hay webhooks para Ethereum, BNB Smart Chain, Polygon, Arbitrum, TRON y Bitcoin, pero no para Solana.

Una entrega fallida no se reintenta automáticamente. Liste las notificaciones fallidas con GET /api/v2/{chain}/webhooks/notifications/failed y envíe una de nuevo con POST /api/v2/{chain}/webhooks/notifications/{id}/retry. Consulte Webhooks y Seguridad de webhooks.

¿Qué tipo de wallet debo usar? Use un wallet protegido con contraseña para direcciones de larga duración. Envíe un password al crear la dirección, y las transacciones posteriores se firman con esa contraseña. Use un wallet no seguro solo para direcciones temporales, porque la clave privada se devuelve en la respuesta y debe guardarla usted. Chaingateway no almacena contraseñas y no puede restaurar una perdida. Consulte Gestión de wallets.

¿Dónde superviso el uso y obtengo soporte?

Sección titulada «¿Dónde superviso el uso y obtengo soporte?»

¿Cómo puedo supervisar mi uso de la API? Puede supervisar su uso de la API desde el panel, que ofrece análisis e informes sobre el número de solicitudes realizadas, el uso de datos y los errores encontrados.

¿Cómo obtengo soporte si tengo problemas? Para obtener soporte, puede contactarnos a través de nuestro portal de soporte disponible en el panel. También ofrecemos un foro comunitario y documentación extensa que puede ayudar a resolver problemas comunes.

Para asuntos urgentes, contacte directamente con nuestro equipo de soporte por correo electrónico en support@chaingateway.io, a través de Telegram, o mediante el chat web del sitio.

También gestionamos una comunidad de Telegram donde encontrará debates útiles.

¿Existe un programa de referidos o de partnership? Sí, ofrecemos programas de referidos y de partnership para desarrolladores y empresas interesados en promocionar Chaingateway.io. Para más información, visite nuestra página de partners.

¿Dónde puedo encontrar las últimas novedades y noticias sobre Chaingateway.io?

Manténgase al día con las últimas noticias, lanzamientos de funcionalidades y anuncios siguiendo nuestro blog y suscribiéndose a nuestro boletín.
