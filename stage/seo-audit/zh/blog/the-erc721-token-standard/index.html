ERC721 代币标准详解：NFT 如何运作

说明 ERC721 标准定义了什么，所有权、授权与转账如何运作，它与 ERC20 有何区别，以及如何通过 API 发送 ERC721 代币并给出 curl 请求示例。文中还解释合约地址为何是唯一可靠的标识，以及手续费和成本如何计算。

章节
C
Chaingateway Team
区块链专家

审核： Maurice Sobiera

ERC721 是以太坊上非同质化代币（NFT）的标准。它定义了智能合约需要实现的通用接口，使每个代币都有唯一的 ID、恰好一个所有者，并拥有同一套转账和授权函数。因此，钱包、市场和 API 可以用相同的方式处理任何 ERC721 合约。

ERC721 标准定义了什么？

该标准规定于 EIP-721。符合标准的合约必须实现 ERC721 接口以及 ERC165 接口，后者让其他合约可以询问某个合约是否支持某个接口。ERC721 接口的 ID 为 0x80ac58cd。

该接口包含三个事件和八个函数（safeTransferFrom 有两种形式）：

项目类型用途
Transfer事件代币所有权发生变化时触发，包括铸造和销毁
Approval事件某个代币的被授权地址发生变化时触发
ApprovalForAll事件所有者启用或禁用某个操作员对其全部代币的权限时触发
balanceOf(owner)函数某个地址拥有的代币数量
ownerOf(tokenId)函数拥有某一代币的地址
safeTransferFrom(from, to, tokenId)函数转移代币，并检查接收方合约能否处理它
transferFrom(from, to, tokenId)函数转移代币，但不做该检查
approve(to, tokenId)函数允许某个地址转移一枚指定的代币
setApprovalForAll(operator, approved)函数允许某个操作员转移调用者的全部代币
getApproved(tokenId)函数返回某一代币的被授权地址
isApprovedForAll(owner, operator)函数说明某个操作员是否已获得某所有者的授权

safeTransferFrom 的第二种形式多一个 data 参数。当接收方是智能合约时，两种形式都会调用其 onERC721Received，若合约未返回预期的值，交易即回滚。这样可以防止代币被发送到无法再次转移它们的合约中。transferFrom 没有此项检查，EIP-721 规定，调用方有责任确认接收方能够处理 NFT。

该标准有两个可选扩展。元数据扩展增加了 name()、symbol() 和 tokenURI(tokenId)，其中 URI 通常指向一个包含名称、描述和图片的 JSON 文件。枚举扩展增加了 totalSupply()，以及按索引列出代币的函数。

如何创建 ERC721 代币？

编写实现该接口的智能合约，编译后将字节码部署到以太坊区块链。多数团队不会手写这些函数，而是从维护中的库开始。OpenZeppelin 的 ERC721 文档介绍了一种经过维护的实现，基于网页的 Remix IDE 则无需本地工具即可编译和部署。

部署会返回一个合约地址。请先在测试网上测试合约，然后再部署到主网。

合约地址是什么，为什么重要？

合约地址是 ERC721 代币集合唯一可靠的标识符。名称和符号并不唯一：任何人都可以部署一个与现有集合同名的合约。代币则完全由合约地址和代币 ID 这一对值确定。

集成 ERC721 代币时，请始终同时保存这两个值。两个不同的合约都可能拥有 ID 为 1 的代币。

ERC721 与 ERC20 有何区别？

ERC20 代币是同质化的：每个单位都可以互换，合约只为每个地址存储一个余额。ERC721 代币是非同质化的：每个代币 ID 都有自己的所有者和元数据。EIP-721 以 ERC20 模型为基础设计，并指出 ERC20 缺乏逐项资产的追踪，因此不适合 NFT。

对于集成而言，实际差异不大，但很容易忽略：

  • ERC20 转账需要一个数量，ERC721 转账需要一个代币 ID。
  • ERC721 合约上的 balanceOf 统计的是代币数量，而不是价值。
  • 除操作员授权外，ERC721 还支持逐个代币的授权。

若要更全面地比较可在一个合约中同时持有同质化与非同质化代币的 ERC1155，请阅读 ERC-721 与 ERC-1155 对比和代币标准详解。我们对 ERC20 的说明见 ERC20 代币标准。

能用 ERC721 代币支付 Gas 费吗？

不能。以太坊上的 Gas 始终以 ETH 支付，即使交易只转移一枚 ERC721 代币。发送地址需要有足够的 ETH 来支付 Gas，手续费等于所用 Gas 乘以 Gas 价格。您可以在 Etherscan 的 Gas 追踪器上查看当前价格，ethereum.org 则说明了手续费的计算方式。

创建一个 ERC721 代币要花多少钱？

部署合约需要消耗 Gas，具体数量取决于所部署合约的大小。每次铸造代币还需要额外的 Gas，根据合约的编写方式，由合约所有者或执行铸造的用户支付。在部署到主网之前，请先在测试网上使用 eth_estimateGas 估算部署费用，再将结果乘以当前的 Gas 价格。

ERC721 代币合法吗？

代币标准本身只是一个技术接口。某项用途是否受监管，取决于代币所代表的内容，以及各方所在的地区。出售代币、接受代币作为付款，或将其作为公司股份发行，都可能涉及牌照、税务，以及了解您的客户（KYC）或反洗钱（AML）义务。在围绕它们开展业务模式之前，请咨询熟悉您所在司法辖区的律师。

如何自动发送 ERC721 代币？

您可以通过 Chaingateway REST API 以脚本方式发送 ERC721 代币，而无需为每笔转账使用钱包。端点为 POST /api/v2/ethereum/transactions/erc721，需要提供发送地址、合约地址、接收地址和代币 ID。Gas 费从发送地址以 ETH 支付。Polygon 和 Arbitrum 有对应的端点（erc721），BNB 智能链则使用 bep721。

必填字段为 from、contractaddress、to 和 tokenId。您也可以传入 privatekey 代替 password。gas、gasprice、maxFeePerGas、maxPriorityFeePerGas 和 nonce 等可选字段可用于控制手续费和交易顺序。调用成功时返回 HTTP 201，交易 ID 位于 data.txid 中。若要先在测试网上试用，请设置请求头 X-Network: testnet。请求参数列于 API 参考中。

若要逐步了解所有权检查、签名和确认的过程，请参阅通过 API 转移 NFT。

还有其他代币标准吗？

有。ERC20 用于同质化代币，ERC-1155 是一种多代币标准，可在单一合约中管理同质化和非同质化代币。在其他网络上，对应的标准名称不同，例如 TRON 上的 TRC-20 和 Solana 上的 SPL。
