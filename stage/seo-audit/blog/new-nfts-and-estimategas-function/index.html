NFT Functions and estimateGas: 2021 Release

What the November 2021 release added: getNFTOwner, getNFTURI, sendNFT and estimateGas, plus how NFT sends and gas lookups work in the v2 API today.

Chapters
C
Chaingateway Team
Blockchain Experts

Reviewed by Maurice Sobiera

Chaingateway’s NFT functions read the owner and metadata URI of an ERC-721, BEP-721 or TRC-721 token and send it to another address. The November 2021 release added getNFTOwner, getNFTURI and sendNFT for Ethereum, Tron and BSC. It also added estimateGas for Ethereum and BSC, which returns a gas estimate for a transaction without sending it.

What is an NFT?

A non-fungible token (NFT) is a token in which every unit has its own token ID. It was first standardised on Ethereum as ERC-721. ERC-20 tokens are interchangeable: any one unit is identical to another. An ERC-721 token is different, because each token ID can have its own owner and its own metadata.

The standard is defined in EIP-721. It specifies ownerOf(tokenId) to return the owner and safeTransferFrom to move a token. The optional metadata extension adds tokenURI(tokenId), which returns a link to the token’s metadata. BEP-721 on BNB Smart Chain and TRC-721 on Tron follow the same model.

EIP-721 standardises a safe transfer function, safeTransferFrom, and an unsafe one, transferFrom. With transferFrom the caller must confirm that the receiving address can handle NFTs. The standard warns that the token may otherwise be permanently lost. Check the receiver before you send a token to a contract address. For a longer introduction, read the ERC721 token standard.

Which NFT functions did the 2021 release add?

The release added three NFT functions. All three were available for the Ethereum, Tron and Binance Smart Chain APIs.

FunctionWhat it doesParameters
getNFTOwnerReturns the owner address of one NFTToken ID, token contract address
getNFTURIReturns the URI of one NFTSame as getNFTOwner
sendNFTSends an NFT to another addressSender address, destination address, contract address, token ID

These names describe the functions as announced in 2021. The documentation of the time was the reference for their exact usage.

Can Chaingateway mint NFTs?

No dedicated mint function was part of this release. You could still mint by encoding the contract call yourself and sending it as a normal transaction with the encoded data.

This is consistent with the standard, because EIP-721 does not define minting. The specification says that creation and destruction of NFTs is not included, and that a contract may implement them by other means. How minting works therefore differs from contract to contract. In 2021 the team said it lacked a test environment for a mint function and asked owners of ERC-721, BEP-721 or TRC-721 contracts to help test one.

What does estimateGas do?

estimateGas returns the amount of gas a transaction is expected to need, before you send it. For Ethereum and BSC, it takes the same parameters as a normal transaction, except for the password. It was added because many users asked for an easier way to calculate gas fees.

The underlying mechanism is the eth_estimateGas method of the Ethereum JSON-RPC interface. According to the Ethereum developer documentation, it generates an estimate without adding the transaction to the blockchain. The same page warns that the estimate may be significantly higher than the gas the transaction actually uses. Treat the result as an upper bound for your gas limit, not as the final cost. A plain transfer of ether, for example, uses 21000 gas, which the same page shows as 0x5208.

What can I use today?

The function names above come from the 2021 API generation. The current public OpenAPI specification (version 2.1.0) is organised differently, so this section lists what it contains as of 5 November 2026.

TaskEndpoint in the v2 specification
Send an ERC-721 token on EthereumPOST /api/v2/ethereum/transactions/erc721
Send a BEP-721 token on BSCPOST /api/v2/bsc/transactions/bep721
Send a TRC-721 token on TronPOST /api/v2/tron/transactions/trc721
Send an ERC-721 token on Polygon or ArbitrumPOST /api/v2/polygon/transactions/erc721, POST /api/v2/arbitrum/transactions/erc721
Read the current gas priceGET /api/v2/ethereum/gasprice, and the same path under bsc, polygon and arbitrum

The specification does not list separate getNFTOwner, getNFTURI or estimateGas endpoints. To read the owner or the URI, call ownerOf or tokenURI on the token contract through any JSON-RPC endpoint. For a gas estimate, use eth_estimateGas the same way. The article on how to estimate gas fees covers the arithmetic.

A send request on Ethereum needs from, contractaddress, to and tokenId. The password field is required unless you pass a privatekey. Gas fields such as gas, gasprice or maxFeePerGas are optional.

A successful call returns status 201 with the transaction hash in data.txid. A wrong wallet password returns 401. A wallet without enough balance to pay for gas returns 422, for example with the message “insufficient funds for gas * price + value”. The addresses above are the placeholder values from the specification. For a full walkthrough, see how to transfer NFTs via API.
