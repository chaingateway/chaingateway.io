Déchiffrer les keystores Ethereum, BNB et Polygon

Comment déchiffrer avec PHP la clé privée d'un fichier keystore Ethereum, BNB ou Polygon, étape par étape, sur le blog Chaingateway.

Introduction

Ethereum, Binance Smart Chain (BSC) et d’autres réseaux compatibles EVM utilisent des fichiers keystore pour protéger les clés privées des utilisateurs. Un fichier keystore est un fichier JSON contenant une clé privée chiffrée, sécurisée par un mot de passe. Pour des raisons de sécurité, les applications ne stockent souvent que le fichier keystore, et non la clé privée en clair.

Dans cet article de blog, nous allons démontrer comment récupérer la clé privée à partir d’un fichier keystore à l’aide de PHP. Cela est particulièrement utile lorsque vous devez exporter ou récupérer votre clé privée pour l’utiliser dans une autre application.

Avertissement

Manipuler directement des clés privées peut être risqué si cela n’est pas fait de manière sécurisée. Assurez-vous toujours que votre environnement est sécurisé et évitez d’exposer inutilement votre clé privée.

Comprendre la structure du keystore

Un fichier keystore typique est un objet JSON contenant des informations chiffrées sur la clé privée. Voici un aperçu des principales sections du fichier :

  • crypto : Contient les informations liées au chiffrement.
    • ciphertext : La clé privée chiffrée.
    • cipher : L’algorithme de chiffrement utilisé.
    • cipherparams : Contient le vecteur d’initialisation (iv) utilisé dans le processus de chiffrement.
    • kdf : Fonction de dérivation de clé (KDF), soit pbkdf2 soit scrypt, utilisée pour dériver la clé de chiffrement à partir de votre mot de passe.
    • kdfparams : Paramètres de la KDF, tels que le sel, les itérations (c) et la longueur de clé (dklen).
    • mac : Code d’authentification de message, utilisé pour vérifier que la dérivation de clé a réussi.

Comment extraire la clé privée

Prérequis

Pour extraire une clé privée d’un fichier keystore, vous aurez besoin des extensions PHP suivantes :

  1. php-json : Pour analyser le fichier keystore (car il est au format JSON).
  2. php-openssl : Nécessaire pour déchiffrer la clé privée (les keystores utilisant AES-128-CTR pour le chiffrement).
  3. php-scrypt : Nécessaire si le keystore utilise la KDF scrypt. En savoir plus ici
