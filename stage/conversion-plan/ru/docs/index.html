Справка по API Chaingateway

Эта справка описывает REST API Chaingateway для семи сетей: Bitcoin, Ethereum, Binance Smart Chain, Tron, Solana, Polygon и Arbitrum. Каждая сеть предоставляет эндпоинты адресов для их создания (в Bitcoin эта версия называется кошельками), а пять из семи — Tron, Ethereum, BSC, Polygon и Arbitrum — также поддерживают импорт существующих адресов. Эндпоинты транзакций охватывают нативные переводы и переводы токенов: TRC20/TRC721/TRC10 в Tron, ERC20/ERC721 в Ethereum, Polygon и Arbitrum, BEP20/BEP721 в BSC и SPL в Solana. Tron, Ethereum, BSC, Polygon, Bitcoin и Arbitrum предоставляют эндпоинты вебхуков для регистрации коллбэков и просмотра доставленных и неудачных уведомлений; у Solana в этой справке нет эндпоинтов вебхуков. Ethereum, BSC, Polygon и Arbitrum дополнительно предоставляют эндпоинт цены gas. Каждый запрос аутентифицируется Bearer-токеном в заголовке Authorization; добавьте заголовок X-Network: testnet, чтобы переключить запрос на testnet, или не указывайте его — либо задайте mainnet — чтобы использовать mainnet.
