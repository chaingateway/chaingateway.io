Aquí respondemos a las preguntas más frecuentes de los desarrolladores

¿Qué es Chaingateway.io? Chaingateway.io es una plataforma integral que ofrece soluciones de API blockchain que permiten a los desarrolladores integrar funcionalidades blockchain en sus aplicaciones. Nuestros servicios son compatibles con varias redes blockchain, lo que permite una interacción fluida y eficiente con los datos y operaciones de la blockchain.

¿Cómo empiezo con Chaingateway.io? Para empezar, regístrese en Chaingateway.io. Una vez registrado, podrá acceder a sus claves de API desde el panel, que necesitará para autenticar sus solicitudes a la API. Nuestra documentación ofrece guías detalladas y ejemplos para ayudarle a integrar nuestras API en su aplicación.

¿Qué redes blockchain son compatibles? Chaingateway.io es compatible con varias redes blockchain, entre ellas:

  • Ethereum
    • Mainnet
    • Sepolia
  • Binance Smart Chain
    • Mainnet
    • Testnet
  • Bitcoin
    • Mainnet
    • Testnet3
  • Polygon
    • Mainnet
    • Amoy
  • Tron
    • Mainnet
    • Nile

Para más información sobre cómo acceder a las distintas redes, visite Redes compatibles.

¿Qué tipo de API ofrece Chaingateway.io? Ofrecemos una gama de API para facilitar distintas operaciones en la blockchain, entre ellas:

  • Gestión de wallets: Crear y gestionar wallets.
  • Gestión de transacciones: Enviar, recibir y supervisar transacciones.
  • Instant Payment Notification: Recibir notificaciones webhook sobre eventos en la blockchain.
  • Recuperación de datos: Obtener datos de la blockchain, como saldos, historiales de transacciones y más.

¿Existen límites de uso para las API? Sí, hay límites de uso según su plan de suscripción. Los planes gratuitos tienen límites más bajos, mientras que los planes de niveles superiores ofrecen cuotas de uso más generosas. Encontrará información detallada sobre los límites y los precios en nuestra página de precios.

¿Cómo gestiono los errores de la API? Si una solicitud a la API falla, la respuesta incluirá un código de error y un mensaje que indica el problema. Los códigos de error comunes son:

  • 400: Bad Request - Su solicitud está mal formada.
  • 401: Unauthorized - Su clave de API no es válida o falta.
  • 403: Forbidden - No tiene permiso para acceder al recurso solicitado.
  • 422: Unprocessable Entity - La solicitud estaba bien formada pero no se pudo procesar debido a errores semánticos.
  • 500: Internal Server Error - Ha ocurrido un problema en nuestro extremo.

¿Puedo probar las API en un entorno sandbox? Sí, ofrecemos un entorno testnet con fines de prueba. Esto le permite probar su integración sin afectar transacciones reales en la blockchain del mainnet, solo en el testnet. El acceso a la sandbox se puede configurar desde su panel.

Consulte Redes compatibles para saber cómo acceder a las distintas redes.

¿Cómo puedo supervisar mi uso de la API? Puede supervisar su uso de la API desde el panel, que ofrece análisis y reportes detallados sobre el número de solicitudes realizadas, el uso de datos y los errores encontrados.

¿Cómo obtengo soporte si tengo problemas? Para obtener soporte, puede contactarnos a través de nuestro portal de soporte disponible en el panel. También ofrecemos un foro comunitario y documentación extensa que puede ayudar a resolver problemas comunes.

Para asuntos urgentes, contacte directamente con nuestro equipo de soporte por correo electrónico en support@chaingateway.io, a través de Telegram, o mediante el chat web del sitio.

También gestionamos una comunidad de Telegram donde encontrará debates útiles.

¿Existe un programa de referidos o de partnership? Sí, ofrecemos programas de referidos y partnership para desarrolladores y empresas interesados en promocionar Chaingateway.io. Para más información, visite nuestra página de partners.

Manténgase al día con las últimas noticias, lanzamientos de funcionalidades y anuncios siguiendo nuestro blog y suscribiéndose a nuestro boletín.
